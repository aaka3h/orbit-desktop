# Orbit 0.2.0 — Beta

Downloadable desktop AI assistant for Linux, Windows, and macOS, with a Hugging Face Model Hub, hardware memory-fit estimates, and readable system/light/dark themes.

## 1. Download the file for your computer

Sign in to GitHub with an account that can access this private repository. Open **Assets** below if the files are collapsed.

## 2. Install and open Orbit

1. **Linux:** open a terminal in the download folder, run `chmod +x Orbit-0.2.0.AppImage`, then `./Orbit-0.2.0.AppImage`. If FUSE is unavailable, try `./Orbit-0.2.0.AppImage --appimage-extract-and-run`.
2. **Windows:** open `Orbit-Setup-0.2.0.exe`, follow the installation wizard, then open Orbit from the Start menu.
3. **Mac:** unzip the correct Mac file, move `Orbit.app` to Applications, then open it.

Read the [step-by-step installation guide](https://github.com/aaka3h/orbit-desktop/blob/v0.2.0/INSTALL.md) for first-run setup and troubleshooting. A copy named `INSTALL.md` is also included in the assets.

These are **unsigned beta builds**. Linux application launch and UI behavior were checked. Windows and Mac packages were cross-built on Linux and have not been tested on their native operating systems; macOS signing/notarization is not configured. Operating-system security checks may block these development builds. Do not disable system-wide security protections.

## 3. Set up your first local AI

1. Install and start [Ollama](https://ollama.com/download). It runs a local model on your computer.
2. In Orbit, open **Model Hub**. Review your detected hardware and choose a model file that fits its estimated memory budget.
3. Review the download size and model card, click **Download**, then choose **Use this model** after it finishes. Public models need no account.
4. Choose a working folder in **Settings → Workspace**. Try: “Read the text files in this folder and summarize them. Do not change anything.”
5. Change text size or the light/dark setting under **Settings → Appearance**.

## 4. Understand this beta

- **79 automated tests passed**, plus the Linux Electron UI and packaged-launch checks.
- Memory-fit labels are estimates. They do not guarantee speed, tool competence, or vision support. No new Hugging Face model was downloaded or benchmarked during release verification.
- The live Llama 3.1 grounding check failed despite receiving the correct file contents. Review model answers and tool results; see the [complete verification report](https://github.com/aaka3h/orbit-desktop/blob/v0.2.0/VERIFICATION.md).
- ChatGPT integration uses the official Codex CLI account login. Claude/Gemini integration uses API keys. Hugging Face Cloud uses a token in this build; browser login needs a registered publisher OAuth client.
- Mouse/keyboard/screenshot tools need the optional Python setup and a suitable vision model. Linux desktop control requires X11; Wayland is unsupported. See [computer-control setup](https://github.com/aaka3h/orbit-desktop/blob/v0.2.0/README.md#5-let-orbit-use-your-computer).

`SHA256SUMS.txt` contains checksums for the application files, source archive, and installation guide. The source archive is `Orbit-0.2.0-source.zip`.
